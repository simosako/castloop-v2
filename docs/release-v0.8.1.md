# castloop v0.8.1

v0.8.0の公開・配信の動作を保ちながら、公開チェックとRSS取り込みの中断時再実行を簡素化し、ヘルプ・同梱Skill・ドキュメントを現行動作へ整合させた版です。

## 主な変更

- **公開チェックの簡素化**：通常の`publish-show`／`publish-episode`は、素材のSHA-256算出とMP3解析を実行中に1回だけ行います。生成したFeed・サイトHTMLは本文のETagで条件付き応答を判定し、`Last-Modified`を送りません。音声・画像はETagに加えてR2の更新時刻確認を維持します。内蔵サイトの一覧ページは、対象ページに載る公開内容だけをSQLiteから読み出します。
- **中断時の再実行の簡素化**：ロックファイルを廃止し、ローカルの記録は一時ファイルからの原子的な置換で保存します。同じワークスペースや取り込み先で変更するCLIは1プロセスだけ実行し、中断後は元プロセスの終了を確認してから、同じ入力でもう一度実行します。RSS取り込みのローカル進捗記録はversion 3のみ対応し、旧version 2の記録は変換しません。
- **ヘルプ・同梱Skill・ドキュメントの整合**：CLIヘルプ、同梱Skill、入力例を現行の動作に合わせました。利用ガイドと設計文書を読みやすく書き直し、旧資料をアーカイブしました。

## 利用を始める

[インストール](installation.md)後、[サービス作成と初回公開](getting_started.md)へ進んでください。

本版は、新規作成するサービス向けです。v0.8.0以前の内部形式を使うサービスからの更新・移行には対応していません。

## 動作確認の範囲

ローカルの自動テストと型検査、およびLinux x64・macOS Apple Silicon・Windows x64での配布バイナリの起動確認を行っています。

本版の変更については、Cloudflareの実環境での確認は行っていません。実機で確認した範囲は、前版の[リリースノート](archive/releases/release-v0.8.0.md)を参照してください。
