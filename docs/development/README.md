# 開発・リリース保守資料

このディレクトリは開発者・リリース担当者向けです。管理者が配布CLIを使うために、ここにあるビルド環境やCI操作を用意する必要はありません。

| 目的 | 参照先 |
| --- | --- |
| ソースの取得後に開発を始める | [CONTRIBUTING.md](../../CONTRIBUTING.md) |
| 現在の構成・処理・データ契約を理解する | [設計文書](../../design/README.md) |
| テストの責務と検証範囲を確認する | [テスト設計](../../design/testing.md) |
| バイナリのビルド・CI・配布を保守する | [ビルドとリリース](releasing.md) |
| 外部Actionの固定先を更新する | [CIのセキュリティ保守](ci_security.md) |
| 配布物を利用する | [CLIのインストール](../installation.md) |

実環境の試験は開発セットアップに含めません。対象・操作範囲の別承認と、[非公開試験の保護条件](../../design/security.md#非公開の実機試験)が必要です。検証結果は確認した版・環境・範囲と未確認事項を記録し、現行ガイドへ時系列ログとして追記しないでください。
