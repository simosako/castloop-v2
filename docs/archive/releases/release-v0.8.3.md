# castloop v0.8.3

This maintenance release improves the documentation and third-party notices. The CLI and Worker have no functional changes from v0.8.2.

## Highlights

- Rewrote the project README and added a Japanese version.
- Added English versions of the user and development guides alongside the Japanese guides.
- Updated the contribution guide and clarified the release procedure. Release notes are now written in English.
- Updated the third-party notices to include Bun, its LGPL components, and the applicable license texts.

## Requirements and updates

Service configuration and supported internal formats are unchanged from v0.8.2. To get started, follow the [installation guide](https://github.com/simosako/castloop-v2/blob/v0.8.3/docs/installation.md) and the [first publication guide](https://github.com/simosako/castloop-v2/blob/v0.8.3/docs/getting_started.md). The guides are also available in [Japanese](https://github.com/simosako/castloop-v2/blob/v0.8.3/docs/README_ja.md).

To update an existing installation, follow the [CLI update instructions](https://github.com/simosako/castloop-v2/blob/v0.8.3/docs/installation.md#update-the-cli). The bundled Worker has no functional changes from v0.8.2.

## Verification

GitHub Actions runs type checking and automated tests on Linux and smoke-tests the release binaries on Linux x64, macOS arm64, and Windows x64. No live Cloudflare testing was performed.
