# Issue #40: 操作記録と再開機能のローカル確認

確認日: 2026-10-19。Linux x86-64、Bun 1.4.2。案Bの操作記録を通常のCLI・Worker経路へ接続し、ローカルSQLと模擬R2/RESTで確認した。利用方法は[操作ガイド](../docs/sqlite_operation_recovery.md)、表の定義は[DDL](sqlite_operation_records_schema.md)を参照する。

## 確認した動作

| 対象 | 確認内容 |
| --- | --- |
| 操作記録 | 登録時の要求元・受信時刻・版番号1の履歴、要求IDの一致判定、拒否された要求の保持 |
| SQLの制約 | 外部キー、状態と成功応答の整合、未対応の記録形式の拒否、既存表の保持 |
| 状態確認 | ページ分割、同じ要求IDの照会、残存ロックがある場合の確認、SQL・journal・ロックを変更しないこと |
| アップロード | PUT成功を読戻し前に保存。読戻しの内容・ETag・部分応答の検証失敗から、PUTを繰り返さずに検証を再開 |
| 応答喪失 | 成功報告・下書き登録の応答喪失を、凍結した要求IDで照合。既存の素材と下書きを再利用 |
| 結果不明のPUT | 同じPUTの再送、取消、削除を拒否して記録を保持 |
| 公開 | キュー受付と操作記録を同じトランザクションで保存。Alarm予約失敗時に両方を取消し、実行・完了の履歴を同じ実行IDで関連付ける |
| 同時操作 | 古い版番号、別操作の素材、変更された対象を拒否。開始と取消が同じ版番号で競合した場合は片方だけを適用 |
| 削除 | 取消後のプレビュー・確認hash、公開要求との競合、ファイル識別情報の不一致、部分完了・結果不明、同じ削除の再実行防止 |
| 保持 | 元のTOML・カバー・音源と操作記録を保持し、未公開素材の削除後も別の一意キーで更新・明示公開できること |
| RSS | 36エピソードの逐次公開、元GUID・公開日時・音源の保持。読戻し中断後は成功済み音源を再PUTせず続行。親と子の操作を関連付ける |
| 容量 | 50/70/85%の警告、大量取り込みの開始前の容量確認、容量が少ない場合も既存操作の結果保存を続けられること |
| 診断情報 | サーバーの操作記録にタイトル・説明・メール・元ファイルのパス・秘密・任意例外文を複製しないこと |

正式CLI entrypointを独立プロセスで起動する試験にも、操作一覧、local/remote確認、取消、削除プレビュー、確認後の削除を追加した。通信はループバックの模擬APIに限定する。

## 強制終了とプロセス排他

新形式の記録は、ローカルSQLiteの`BEGIN EXCLUSIVE`で排他する。次を確認した。

1. 保持中のロックを別プロセスが取得できない。
2. 同じプロセス内での取得失敗が、元のOSロックを解放しない。
3. 保持中のプロセスをSIGKILLすると、別プロセスが取得できる。
4. 旧形式の残存`.lock`や、排他用ファイルへのsymlinkを拒否する。

排他部分だけの検証プログラムもLinux単体実行形式へコンパイルし、`PATH`にBun/Node.js/外部コマンドがない状態で、同時取得の拒否とSIGKILL後の取得を確認した。実際のCloudflare通信中に正式CLIを強制終了する試験とは区別する。

## 記録量の小規模確認

実装したSQLへ、2素材を扱うupload操作を100件追加した。各操作は登録と、各素材の開始・成功報告・検証・下書き登録まで行う。

| 項目 | 結果 |
| --- | --- |
| 操作 / 要求 / 履歴 / 素材 | 100 / 900 / 900 / 200行 |
| SQLiteの`total_changes()`増分 | 3,800行 |
| DB容量の増分 | 909,312 bytes |
| 操作あたりの容量増分 | 約9.1KB |

初期DDLの容量を除いたBun内蔵SQLiteの測定である。`total_changes()`は索引の更新を含むCloudflareの課金行数ではなく、DOの内部管理データも再現していない。容量計画は引き続き20KB/操作を用い、SQLの自動期限削除は追加しない。

## 実環境で確認する事項

本書のローカル試験の後、別途承認された隔離環境で正常公開と2種類のSIGKILL試験を実施した。[小規模実機確認](sqlite_operation_records_live_verification_20261019.md)を参照する。CPU・日次課金行数や大容量・高負荷は未測定であり、ローカル試験と実機確認の範囲を分けて扱う。
