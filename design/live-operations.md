# 実環境操作の承認と保護対象

Cloudflareの実環境を操作する前と、ローカルの試験記録を整理・削除する前に読む文書です。共通の作業規則は [AGENTS.md](../AGENTS.md)、非公開実機試験の保護条件は[セキュリティ設計](security.md#非公開の実機試験)を参照してください。実施手順は試験目的に合わせて選びます。[実機試験の標準シナリオ](live-trial.md)は、新規サービスでShowと3件のEpisodeを公開する場合の手順です。

## 操作前に確認すること

対象アカウント、リソース、実施する操作を特定し、明示承認の範囲と照合します。リソースの作成・削除、配備、コンテンツ公開、DNS・ドメイン変更、権限、料金・CPU上限の変更、ローカル試験記録の整理・削除は、それぞれ承認された範囲で行います。

コード変更、テスト成功、コミット、push、skillの読み込み、過去の作業承認は、今回の実環境操作の承認にはなりません。操作前にAPIで現在の状態を確認し、対象や許可範囲が不明なら、その操作を始める前に確認します。性能などの問題に対し、Paidプランへの変更を回避策として要求しません。

前回の試験記録は、設定や素材の候補を調べるために使えます。今回の対象アカウント・リソース・確認者・保護設定は改めて確認し、承認を得た値だけを使います。前回の確認者やAccess設定を、そのまま今回の許可として引き継ぎません。

## 維持する対象

| 対象 | 扱い |
| --- | --- |
| `otftalk.com` の試験対象以外のDNS | 試験やその後片付けの対象から除外する |
| 共有証明書、アカウント全体の保護設定、共有ログイン元 | 専用の試験設定と区別し、維持する |
| ローカルの音声・画像などの原本 | 保全してコピーを使う。試験用コピーと取り違えて変更・削除しない |
| 非公開の試験記録 | 保全し、整理・削除には対象を指定した別途承認を得る |
| 廃棄済み環境のリソース名 | 再利用せず、新しい試験には未使用の名前を選ぶ |

この表は保護条件であり、操作対象の一覧ではありません。実際に変更する対象は、その回の承認と現在状態から確認します。
